## Getting Started

1. Open terminal and change directory to backend folder using
```cd backend```
2. Install dependencies using
```npm install```
3. Run backend using
```npm run dev```

### Frontend
1. Open terminal and change directory to backend folder using
```cd frontend```
2. Install dependencies using
```npm install```
3. Start application using
```npm start```
